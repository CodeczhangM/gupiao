# 全局 MACD 参数设置设计

## 目标

为量化系统增加一套由 MySQL 持久化、页面可修改的全局 MACD 参数。默认参数为：

- 快线周期：5
- 慢线周期：34
- 信号周期：5

参数必须应用于所有参与选股和信号判断的 MACD 计算，包括自由复盘、日线策略、实时共振、实时信息、隔夜选股、次日早盘跟进，以及个股和板块的 60 分钟信号。

## 范围和约束

- 页面提供“保存并重新计算”这一项明确操作，输入过程不触发计算。
- 三个周期必须是 `2–120` 的整数，且快线周期必须小于慢线周期。
- MySQL 是全局配置的唯一权威来源，所有浏览器和 Python 服务进程使用同一份配置。
- 修改参数后保留日线和分钟行情原始缓存，不重新下载行情。
- 修改参数后必须使旧参数生成的实时结果和自由复盘结果失效。
- 保存或重新计算失败时，不能留下部分更新的配置或把可用结果直接清空。
- API 和页面必须展示当前结果对应的 MACD 参数及配置版本。

## 架构

### 统一配置和计算

新增独立的 MACD 配置模块，负责：

- 初始化全局指标配置表；
- 读取当前 MACD 配置；
- 校验并原子更新配置；
- 生成稳定的参数标识，例如 `macd-5-34-5-v2`；
- 提供统一的 pandas MACD 计算函数。

其他策略文件不再自行写死 `12/26/9`，全部通过公共函数计算 DIF、DEA 和柱值。公共函数允许测试显式传入参数，生产代码默认读取当前全局配置。

### 配置持久化

MySQL 新增单行全局配置表，至少包含：

- `config_key`
- `fast_period`
- `slow_period`
- `signal_period`
- `config_version`
- `updated_at`

首次初始化写入 `5/34/5`。更新使用事务和行锁：先校验，再增加配置版本并提交；失败则回滚，旧参数保持可用。

### 缓存和快照隔离

仅清空结果缓存，不清空原始行情缓存。

- 内存实时结果缓存的 key 加入 MACD 参数标识。
- MySQL `realtime_result_cache.cache_key` 加入 MACD 参数标识，旧记录自然不会命中。
- 隔夜、早盘和实时信息的进程内结果 key 加入参数标识。
- 自由复盘的 `SCORE_VERSION` 派生出 MACD 参数标识，或新增等价的参数版本字段，保证旧快照不会被新配置查询命中。
- 更新配置后启动自由复盘后台重建；实时类结果在下一次请求时使用原始行情缓存按新参数重新计算。

旧结果可以保留用于排错和历史比较，但不能作为当前配置的快速结果返回。

## 保存并重新计算流程

1. 前端读取当前参数、配置版本和更新时间。
2. 用户输入三个周期并点击“保存并重新计算”。
3. Spring 将请求体原样转发给 Python。
4. Python 校验参数。
5. Python 在事务中更新 MySQL 配置并增加版本号。
6. Python 清理当前进程的派生结果内存缓存。
7. Python启动最新完整交易日的自由复盘后台构建。
8. 接口返回新参数、配置版本和构建状态。
9. 前端轮询构建状态，并在实时信息等页面显示当前使用的 `MACD 5/34/5`。

如果第 5 步失败，配置不变。如果配置已提交但后台构建失败，接口明确返回构建失败状态；旧版本结果仍保留，但页面标记其参数版本与当前配置不一致，不将其冒充为新结果。

## API

Python 和 Spring 增加对应接口：

- `GET /api/indicator-settings/macd`
- `PUT /api/indicator-settings/macd`

Spring 路径位于 `/api/quant/indicator-settings/macd`。

读取响应包含：

```json
{
  "fast_period": 5,
  "slow_period": 34,
  "signal_period": 5,
  "config_version": 2,
  "parameter_key": "macd-5-34-5-v2",
  "updated_at": "2026-07-31 10:00:00"
}
```

更新请求包含三个周期。更新响应除当前配置外，还包含自由复盘构建状态。

## 页面

在自由复盘页面增加全局设置区：

- 快线周期输入框；
- 慢线周期输入框；
- 信号周期输入框；
- 当前配置版本和更新时间；
- “保存并重新计算”按钮；
- 参数校验错误；
- 自由复盘重建状态。

实时共振、实时信息、隔夜和次日早盘页面的数据信息区展示当前 MACD 参数，便于确认结果口径。

## 测试

- 配置表初始化默认值为 `5/34/5`。
- 参数校验拒绝非整数、超范围和快线不小于慢线。
- 更新成功时版本递增，更新失败时事务回滚。
- 公共 MACD 函数与 pandas 的 `ewm(5/34/5)` 结果一致。
- 所有原硬编码 MACD 位置改为公共函数，并通过策略回归测试。
- 配置版本改变后，旧内存/MySQL结果缓存不再命中。
- 自由复盘只查询当前参数版本快照。
- Python API、Spring 转发和前端设置交互均有回归测试。
- 实时共振、实时信息、隔夜和次日早盘的现有兼容套件继续通过。
