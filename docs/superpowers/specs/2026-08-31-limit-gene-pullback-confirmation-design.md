# 涨停基因与回踩突破确认候选模型设计

## 目标

将“近期观察与建仓”从依赖当日共振的模型，升级为面向保守型建仓的中短周期模型。候选必须具备前期涨停基因，允许共振发生在近20个交易日内，并优先选择回踩关键位不破、随后重新突破确认位的股票。

模型输出仍限制为0至10只，不为数量补入弱股票。当天涨停、跌停或封板股票不进入建仓榜，但保留在调试漏斗中。

## 适用范围

- 仅修改“近期观察与建仓”候选池、评分、解释字段和过滤调试。
- 继续限制沪深主板、非ST、正常交易股票。
- 不修改独立的盘末隔夜溢价、次日早盘跟进、自由复盘和其他选股池。
- 继续使用全局MACD参数，并将规则版本纳入缓存键。

## 总体流程

1. 从主板股票中排除ST、退市、停牌和无有效价格股票。
2. 检查前1至10个交易日是否至少出现一次有效涨停；今天不计入历史涨停。
3. 提取近20个交易日内的共振事件并按发生时间衰减。
4. 计算涨停启动位、平台、均线、筹码峰和突破位等关键位。
5. 判断回踩是否守住关键位，并识别回踩后的突破确认位。
6. 计算七项正向分、风险扣分和硬性否决项。
7. 输出立即建仓、等待突破建仓、观察建仓或不展示。
8. 返回完整过滤漏斗、过滤原因和样本解释。

## 必选资格：前1至10日涨停基因

候选必须在今天之前的第1至第10个交易日内至少出现一次有效涨停。

- 主板普通股票使用涨幅不低于9.5%或可靠行情字段标记涨停。
- 今天涨停不能替代历史涨停资格。
- 第10个交易日的涨停有效，第11个交易日及更早无效。
- 多次涨停时保存最近一次涨停，并可额外记录窗口内涨停次数。
- 输出字段包括最近涨停日期、距今天数、涨停收盘价、实体低点、启动价和窗口内涨停次数。

当天涨停、跌停或封板股票不进入建仓榜。调试原因必须区分：

- 当日涨停或接近涨停，并显示实际涨幅和9.5%阈值；
- 当日跌停或接近跌停，并显示实际跌幅和-9.5%阈值；
- 行情源明确标记封板，并显示当前价、涨跌幅、数据时间和数据源。

## 近20日历史共振

共振不要求发生在今天。有效事件包括：

- 日线MACD金叉或由弱转强；
- 60分钟MACD/KDJ共振；
- 放量突破；
- 底部首阳；
- 缩量企稳。

时间衰减：

- 1至3个交易日：保留100%事件分；
- 4至7个交易日：保留80%；
- 8至12个交易日：保留60%；
- 13至20个交易日：保留40%；
- 超过20个交易日：不计入。

同类事件只保留最近一次或衰减后最强的一次，避免同一信号重复堆分。每个候选返回共振类型、日期、距今天数、原始强度、衰减系数和贡献分。

近20日没有任何有效共振的股票不展示。

## 关键位识别与合并

关键位来源包括：

1. 最近涨停K线实体低点；
2. 最近涨停启动价；
3. 涨停后的整理平台下沿和平台上沿；
4. MA10和MA20；
5. 筹码主峰成本区；
6. 前期突破位。

距离足够接近的关键位合并为支撑区。价格差不超过1.5%视为同一区域，最多保留三个有效支撑区。来源越多、时间越近、成交验证越充分，支撑区强度越高。

主关键位是当前价格下方或附近、强度最高的有效支撑区。输出主关键位价格、支撑区上下界、来源列表、强度、当前距离百分比和是否守住。

## 回踩与突破确认

回踩状态分为：

- 关键位上方企稳；
- 回踩关键位未破；
- 盘中跌破但收回；
- 有效跌破关键位。

放量跌破主关键位或跌破全部有效支撑区属于高风险否决项，不展示。

“立即建仓”必须完成回踩后的二次确认：

- 历史上已经出现有效回踩，最低价没有有效跌破主关键位；
- 当前收盘价或可靠实时价重新突破确认位；
- 突破幅度至少达到确认位上方0.5%；
- 突破时量比位于1.2至3.0，或成交额明显高于回踩阶段；
- 日线或60分钟MACD至少一个向上，二者不能同时走弱；
- 当日涨幅不超过7%；
- 当前价格没有明显远离筹码主峰；
- 不存在放量滞涨、显著长上影或尾盘明显抛压等否决项。

确认位按以下优先级确定：

1. 回踩后的局部高点；
2. 涨停后平台上沿；
3. 前期突破位；
4. MA10、MA20与筹码主峰形成的共振压力位。

输出确认位价格、来源、突破幅度、是否突破和量价是否确认。

## 评分权重

正向总分100分：

- 回踩不破关键位：30分；
- 近20日历史共振：20分；
- 热点板块状态：18分；
- 量价与主力：12分；
- 筹码峰结构：8分；
- 当前日线/60分钟MACD：7分；
- 相对强弱与尾盘承接：5分。

涨停基因是资格门槛，不额外计分。各分项使用有界分段规则，不直接放大无界原始数值。

风险扣分最多30分，继续覆盖换手过热、成交异常放大、放量滞涨、远离筹码峰、尾盘抛压和当日涨幅过热等风险。硬性否决不依赖最终总分。

## 建仓等级

### 立即建仓

- 总分不低于80；
- 关键位分不低于22；
- 已完成“回踩不破 + 突破确认位 + 量价确认”；
- 当前价位于主关键位上方且距离不超过5%；
- 板块不弱；
- 日线与60分钟MACD不同时走弱；
- 无高风险否决项和必要确认缺失。

### 等待突破建仓

- 总分不低于65；
- 已守住至少一个有效关键位；
- 尚未突破确认位，或突破后量价确认不足；
- 总分达到80但缺少尾盘、筹码或分钟确认时也降至此等级。

### 观察建仓

- 总分为50至64；
- 具备涨停基因和近20日有效共振；
- 仍守住至少一个有效关键位；
- 处于整理、靠近关键位或等待回踩完成阶段。

### 不展示

- 总分低于50；
- 无前1至10日涨停基因；
- 近20日无有效共振；
- 当天涨停、跌停或封板；
- 放量跌破主关键位或跌破全部关键位；
- 日线与60分钟MACD同时显著走弱；
- 其他高风险否决项。

## 缺失数据降级

- 历史日线不足以判断10日涨停资格时不展示，并明确标记“历史日线不足”。
- 近20日事件数据部分缺失时，使用可验证事件，不制造默认共振。
- 筹码数据缺失时筹码分为0，不能立即建仓，但可进入等待或观察。
- 尾盘窗口尚未到时不扣风险分，但不能立即建仓。
- 尾盘窗口已到但分钟数据缺失时标记缺失确认并降级。
- 单只股票计算异常必须隔离，不能中断整批候选。

## 过滤调试

调试区返回并展示以下漏斗：

- 原始主板数量；
- 无前1至10日涨停基因数量；
- 当天涨停数量；
- 当天跌停数量；
- 行情源封板数量；
- 近20日无共振数量；
- 跌破关键位数量；
- 综合分不足数量；
- TOP排序截断数量；
- 最终候选数量。

样本解释必须包含：股票代码、名称、当前价、涨跌幅、数据时间、数据源、最近涨停日期、最近共振日期、主关键位、确认位、总分、各分项分、风险扣分和最终过滤原因。

当最终候选为0时自动展开调试区。原因必须来自实际过滤分支，不能用笼统的“条件不足”替代。

## 缓存与版本

- 新规则使用评分版本`position-candidate-v2-limit-gene-pullback`。
- 版本继续附加全局MACD参数键。
- 实时结果缓存键必须包含新版本，避免旧模型结果混入。
- 历史涨停、历史共振和关键位按股票与交易日缓存；强制刷新仅更新当天价格、分钟确认和受当天数据影响的状态。

## 测试与验收

必须覆盖：

- 第1日至第10日涨停有效，第11日无效，今天涨停不算历史资格；
- 当天涨停、跌停和行情源封板分别产生准确原因；
- 20日共振在四个时间区间的衰减边界；
- 同类共振不重复堆分；
- 多来源关键位识别、1.5%合并、主关键位选择；
- 回踩不破、盘中跌破收回、有效跌破和放量跌破；
- 回踩优秀股票优先于只有板块或筹码优势的股票；
- 立即建仓必须完成突破确认和量价确认；
- 未突破确认位只能进入等待突破建仓；
- 缺分钟、筹码或尾盘数据时正确降级；
- 单股异常隔离；
- 调试漏斗计数与样本原因一致；
- 最终输出0至10只，不补入弱股票；
- 独立隔夜溢价与其他模块保持不变。

## 部署观察

部署后先强制刷新一次以生成新版本缓存。通过调试漏斗观察“无涨停基因”“无20日共振”“跌破关键位”和“评分不足”的数量。如果连续多个交易日稳定为0，应优先检查事件数据覆盖和关键位识别，不应直接降低硬门槛。
