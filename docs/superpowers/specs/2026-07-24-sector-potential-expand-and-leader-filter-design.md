# 板块潜力展开与推荐股过滤设计

## 目标

在“板块上涨潜力排序”中支持点击板块展开查看推荐股票，并让推荐股票更符合中大市值白马股的低位启动后回踩确认形态。

## 行为

- 板块潜力表的每个板块行可展开或收起。
- 展开区展示该板块的推荐股票：代码、名称、涨跌幅、收盘价、换手、量比、总市值和推荐理由。
- 推荐股票必须满足：
  - 总市值不低于 200 亿元。`total_mv` 按 Tushare 常见单位“万元”处理，统一转成 `total_mv_yuan` 后判断 `>= 20_000_000_000`。
  - 均线多头向上，使用最近行情计算 MA5、MA10、MA20，要求 `MA5 > MA10 > MA20` 且 MA5、MA10、MA20 最近 3 日向上。
  - 近 60 个交易日内出现过涨停，且涨停发生时处于近 60 日区间低位。
  - 最近 3 个交易日内完成回踩确认：涨停后回踩，收盘守住 MA20 或涨停启动区上沿，且回踩日未放出异常高量。
  - 前期充分横盘震荡或当前处于震荡洗盘箱体内部。
- 板块自身排序仍沿用现有 `potential_score` 逻辑；本次只改变板块展开和 `leader_stocks` 推荐质量。

## 实现

- 后端在 `strategy.py` 为 `_select_sector_leaders()` 增加历史数据输入，计算推荐股形态信号并过滤候选。
- `rank_sector_potential()` 给每个板块选择 leader 时传入该板块历史行情。
- 前端在 `quantClient/main.js` 的 `SectorPotentialTable` 增加本地展开状态。
- `quantClient/sector-potential-utils.js` 增强推荐股文本，显示总市值和推荐理由。

## 测试

- Python 单测覆盖新推荐股硬条件。
- JavaScript 单测覆盖推荐股展示文本。
- 手工/静态检查确认板块行可展开，空推荐股有明确占位。
