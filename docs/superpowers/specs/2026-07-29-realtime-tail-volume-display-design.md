# 实时信息尾盘量能展示设计

## 目标

在“实时信息”页面的“实时共振”和“隔夜选股”两张表中增加独立的“尾盘量能”列，明确标出尾盘是否放量以及具体倍数。

本次仅完善前端展示，不改变实时共振或隔夜选股的筛选、评分和排序。

## 数据来源

复用接口已有字段：

- `tail_volume_ratio`：14:30 后平均分钟成交量相对 14:30 前平均分钟成交量的倍数；
- `tail_after_1430_available`：14:30 后数据是否可用。

不新增接口字段，不在前端重新计算成交量。

## 展示规则

两张表均新增“尾盘量能”列，并使用相同规则：

- `tail_after_1430_available !== true` 且当前时间早于 14:30：显示灰色“未到”；
- `tail_after_1430_available !== true` 且当前时间不早于 14:30：显示灰色“无数据”；
- 数据可用但 `tail_volume_ratio` 不是有效数值：显示灰色“无数据”；
- `tail_volume_ratio >= 1.5`：显示绿色徽标“放量 X.XX倍”；
- `tail_volume_ratio < 1.5`：显示普通灰色徽标“正常 X.XX倍”。

`1.5` 是唯一的尾盘放量展示阈值。数值沿用页面现有格式化规则。

## 前端结构

新增独立的纯展示工具，负责把行数据和“是否已到 14:30”转换为：

- `text`：表格显示文案；
- `state`：`strong` 或 `muted`，复用现有徽标颜色。

Vue 页面方法只负责传入行数据和当前时间状态。这样可以用 Node 测试直接覆盖展示规则，不依赖浏览器或后端。

“实时共振”表由 10 列变为 11 列；“隔夜选股”表由 11 列变为 12 列。两张表空状态行的 `colspan` 同步更新。

## 测试

使用 Node 内置测试框架覆盖：

1. 1.5 倍显示“放量 1.50倍”和 `strong`；
2. 1.49 倍显示“正常 1.49倍”和 `muted`；
3. 14:30 前数据不可用显示“未到”；
4. 14:30 后数据不可用显示“无数据”；
5. 可用标记存在但倍数无效时显示“无数据”。

同时运行现有前端工具测试，确认新增脚本加载后没有回归。
