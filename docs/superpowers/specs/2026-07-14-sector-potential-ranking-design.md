# 板块上涨潜力排序设计

## 背景

当前量化看板的 `scan` 流程已经从行情缓存读取最近 100 个工作日数据，并输出趋势突破、超跌反转、主升浪启动、强势板块和板块尾盘候选股。用户希望在前端新增一个板块，用现有 `scan` 数据预测未来板块上涨潜力排序，并选出潜力板块里的龙头股。

本设计复用现有扫描链路，不新增独立数据源。目标是把“短线延续概率”和“3-10 日波段潜力”同时呈现，帮助用户区分隔日资金延续、超跌反包和更可能形成主线的板块。

## 目标

- 在 `scan` 报告中新增 `sector_potential` 字段。
- 基于最近 100 个交易日的全市场日线和最新交易日快照，为行业板块计算潜力排序。
- 每个板块输出综合分、短线分、波段分、信号类型和关键解释指标。
- 每个高潜力板块选出 3-5 只龙头股/领涨股。
- 前端新增“板块潜力”页，展示排序表和龙头股。
- 保持现有 `scan`、历史报告和前端页面兼容；缺少历史数据时降级为空数组或低置信度结果。

## 非目标

- 不接入新的外部资讯、研报、股吧或舆情数据。
- 不做确定性涨跌预测，不输出买卖建议。
- 不新增实时盘中接口。
- 不改变现有超跌反转、趋势突破、主升浪启动策略规则。

## 数据输入

后端在 `run_quant_scan()` 中已有：

- `df`：最新交易日完整市场快照，包含行业、涨跌幅、成交额、换手率、量比、市值等字段。
- `hist_df`：最近 100 个交易日全市场日线，包含 `ts_code`、`trade_date`、`close`、`high`、`low`、`vol`、`amount`、`pct_chg`。
- `breakout`、`first_limit`：现有股票池，可作为龙头股加分信号。
- `moneyflow_summary`：板块资金流摘要，可用于解释但不作为硬依赖，因为资金流日期可能滞后。

`hist_df` 不包含行业字段时，通过最新 `df` 的 `ts_code -> industry/name/amount/turnover_rate/volume_ratio/total_mv` 映射补齐。

## 后端设计

新增策略函数：

```python
rank_sector_potential(
    market_df: pd.DataFrame,
    history_df: pd.DataFrame,
    breakout_pool: pd.DataFrame | None = None,
    first_limit_pool: pd.DataFrame | None = None,
    limit: int = 20,
    leaders_per_sector: int = 5,
) -> pd.DataFrame
```

函数职责：

- 汇总板块最近 1/3/5/20/60/100 日收益。
- 计算板块相对全市场强弱。
- 计算最新交易日上涨比例、强势股比例、涨停数量、成交额放大倍数和活跃度。
- 计算板块当前在 60/100 日区间中的位置。
- 计算短线分、波段分、综合分。
- 为每个板块选出龙头股。
- 返回可直接序列化的 DataFrame。

`run_quant_scan()` 新增：

```python
sector_potential = rank_sector_potential(
    df,
    hist_df,
    breakout_pool=breakout,
    first_limit_pool=first_limit,
    limit=limit,
)
```

并在返回值中加入：

```python
"sector_potential": dataframe_to_records(sector_potential, limit)
```

历史报告保存逻辑需要同步保存和读取该字段；旧报告没有该字段时返回 `[]`。

## 评分模型

### 短线延续分

短线分关注 1-3 个交易日延续概率：

- 最新交易日板块平均涨幅。
- 最新交易日上涨家数比例。
- 最新交易日强势股比例，默认 `pct_chg >= 5%`。
- 最新交易日涨停或接近涨停数量，默认 `pct_chg >= 9.8%`。
- 板块成交额相对上一交易日放大倍数。
- 板块平均量比和平均换手。
- 前一交易日抗跌能力：若全市场弱而板块跌幅小或上涨，加分。

### 波段潜力分

波段分关注 3-10 个交易日主线形成概率：

- 20/60/100 日板块收益。
- 20/60 日相对全市场收益。
- 近 5 日收益和近 5 日成交额变化。
- 60/100 日区间位置。中高位趋势加分，极高位过热扣分。
- 板块内部扩散：20 日相对强势股票数量占比。
- 过热风险：连续大涨、位置过高且成交急剧放大时扣分。

### 综合分

默认综合分：

```text
potential_score = short_score * 0.45 + swing_score * 0.55
```

短线分更适合隔日跟踪，波段分更适合观察未来几天主线。综合分默认用于前端排序。

### 信号类型

根据分数组合和关键指标输出：

- `短线延续`：短线分高，13/14 日这类抗跌后走强、放量扩散的板块。
- `波段主线`：波段分高，20/60 日相对强且趋势未明显过热。
- `超跌反包`：前一日大跌，最新交易日强反弹，但中期趋势尚未确认。
- `观察`：分数不低但关键条件不足。

## 龙头股选择

每个板块选 3-5 只龙头股，优先级：

- 最新交易日涨幅靠前。
- 最新交易日成交额、换手率、量比靠前。
- 近 20 日相对本板块更强。
- 进入现有 `breakout` 或 `first_limit` 池的股票加分。
- 市值和成交额过低的股票降权，避免纯流动性噪音。

龙头股输出字段：

- `ts_code`
- `name`
- `pct_chg`
- `close`
- `turnover_rate`
- `volume_ratio`
- `amount`
- `leader_score`
- `leader_reason`
- `pool_tag`，可为 `趋势突破`、`主升浪启动` 或空值。

## 前端设计

新增导航按钮：`板块潜力`。

新增页面内容：

- 顶部摘要：潜力板块数量、最高综合分、短线最强板块、波段最强板块。
- 主表：展示板块排序。
- 龙头股：在表格行内以紧凑列表展示，或在右侧面板展示当前行龙头股。第一版采用表格内紧凑列表，减少状态复杂度。

表格列：

- 排名
- 板块
- 综合分
- 短线分
- 波段分
- 信号
- 今日涨幅
- 上涨比例
- 放量倍数
- 20 日相对强弱
- 60 日相对强弱
- 龙头股
- 理由

总览页可新增一个小面板显示 `sector_potential` Top 8，点击进入“板块潜力”页。

## 错误处理与降级

- `history_df` 为空：返回 `[]`，前端显示暂无数据。
- 历史交易日少于 20 个：只输出短线分，波段分为 `None` 或低置信度，理由说明历史不足。
- 个别板块样本数少于 8：默认排除，避免小样本噪音。
- 旧历史报告没有 `sector_potential`：前端显示暂无数据，不报错。
- 资金流日期滞后：不阻塞潜力排序。

- 验证“超跌反包”板块被标为 `超跌反包`。
- 验证龙头股优先选择涨幅、成交额、量比强且进入现有股票池的股票。
- 验证历史不足时不抛异常。
- 验证 `run_quant_scan()` 返回 `sector_potential`。
- 验证数据库保存和读取兼容旧报告。

前端测试：

- 若现有前端测试环境适合，增加格式化/派生数据测试。
- 手工验证“板块潜力”页在空数据、有数据、旧报告三种状态下布局正常。
