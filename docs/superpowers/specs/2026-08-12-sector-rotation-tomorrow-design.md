# 明日板块轮动模块设计

## 背景

现有量化看板已经有板块潜力排序、板块资金流摘要、自由复盘宽表和板块内龙头股推荐能力。用户希望新增一个独立模块，根据最近两天的板块轮动情况，推测明天可能获得资金流入的板块，并列出每个推荐板块里最可能拉升的股票。

本设计采用独立模块，不把新逻辑混入已有“板块潜力”页。原因是已有板块潜力偏 3-10 日综合上涨潜力，而本模块聚焦“明日资金流入方向”，需要同时区分追强延续和轮动回流。

## 目标

- 新增独立前端页签：`明日轮动`。
- 新增后端 API，输出两个有排序、有分数的板块榜单：
  - `延续流入榜`：今日已有资金攻击，明天可能继续流入。
  - `轮动回流榜`：资金从流出转改善或弱转强，明天可能被轮到。
- 每个榜单按 0-100 分排序，默认展示 Top 10。
- 每个推荐板块下输出两组股票：
  - `进攻龙头`：板块延续时最能代表强度的票。
  - `补涨候选`：板块回流或扩散时更可能被资金补拉的票。
- 主信号使用最近 2 个完整交易日，辅助参考 5/20 日趋势背景。
- 在资金流缺失或日期滞后时降级展示，不输出强确定性结论。

## 非目标

- 不接入新闻、研报、股吧、社媒或大模型舆情。
- 不做确定性涨跌预测，不输出买卖指令。
- 不新增实盘自动交易能力。
- 不替代现有板块潜力、自由复盘和实时尾盘溢价模块。
- 第一版不做历史命中率回测页面。

## 数据输入

后端复用现有缓存和计算能力：

- `market_cache.get_complete_dates()`：获取最新完整交易日。
- `market_cache.load_market_snapshot(trade_date)`：最新市场快照，包含股票行业、涨跌幅、成交额、换手率、量比和市值等字段。
- `market_cache.load_recent_daily(trade_date, n=20)`：最近 20 个交易日全市场日线。
- `market_cache.load_moneyflow(trade_date)` 或现有资金流缓存表 `sector_moneyflow_daily`：东方财富行业板块资金流 `moneyflow_ind_dc`。
- `strategy.rank_sector_potential()` 的现有板块强弱和龙头股思想，可复用部分指标口径。
- 可选：自由复盘最新快照里的 `total_score`，用于补涨候选的质量加成。缺失时不阻塞。

关键日期：

- `trade_date`：用于生成报告的最新完整交易日，默认取最近完整交易日。
- `lookback_trade_dates`：最近两个完整交易日，用于板块轮动主判断。
- `context_trade_dates`：最近 5/20 个完整交易日，用于趋势背景和过热过滤。
- `moneyflow_trade_dates`：实际使用到的资金流日期。若资金流日期与行情日期不一致，结果降低置信度并在 warnings 中说明。

## 后端架构

新增服务模块：

```python
sector_rotation_service.py
```

核心入口：

```python
def build_tomorrow_sector_rotation(
    trade_date: str | None = None,
    limit: int = 10,
    stocks_per_sector: int = 5,
) -> dict[str, Any]:
    ...
```

主要步骤：

1. 确定最新完整交易日和最近 2/5/20 日交易日。
2. 加载最近两天板块资金流。
3. 加载最近 20 日行情和最新市场快照。
4. 聚合行业级行情指标：
   - 板块平均涨幅
   - 上涨家数比例
   - 强势股比例
   - 涨停或接近涨停数量
   - 成交额放大
   - 5/20 日收益和相对强弱
   - 20 日区间位置和过热风险
5. 聚合行业级资金流指标：
   - 两日净流入
   - 今日净流入
   - 净流入变化
   - 净流入率变化
   - 是否由流出转流入
   - 流出是否显著收窄
6. 分别计算 `continuation_score` 和 `rotation_score`。
7. 为每个入榜板块选择 `attack_leaders` 和 `catchup_candidates`。
8. 返回两个按分数降序排序的榜单。

## 板块评分模型

所有板块分数为 0-100。每个子项先标准化为 0-100，再按权重合成，最后扣除风险分并截断到 0-100。

### 延续流入分

`continuation_score` 用于 `延续流入榜` 排序：

```text
continuation_score =
  30% 两日资金连续性
+ 20% 今日净流入强度
+ 15% 净流入加速
+ 15% 板块涨幅和上涨家数扩散
+ 10% 成交额放大
+ 10% 龙头强度
- 过热风险扣分
```

子项口径：

- 两日资金连续性：最近两个资金流日均为正、且排名靠前得高分。
- 今日净流入强度：今日 `net_amount` 和 `net_amount_rate` 的行业内分位。
- 净流入加速：今日净流入高于前一日，或由小流入转大流入。
- 板块扩散：今日平均涨幅、上涨比例、强势股比例共同决定。
- 成交额放大：今日板块成交额相对前一日和近 5 日均值放大。
- 龙头强度：板块内进攻龙头的最高分和前 3 平均分。
- 过热风险：20 日位置极高、两日累计涨幅过大、成交急剧放大且上涨家数未扩散时扣分。

### 轮动回流分

`rotation_score` 用于 `轮动回流榜` 排序：

```text
rotation_score =
  30% 资金改善幅度
+ 20% 由流出转流入或流出显著收窄
+ 15% 今日板块抗跌或转强
+ 15% 5/20 日趋势未破坏
+ 10% 板块内补涨空间
+ 10% 成交活跃改善
- 弱趋势和流动性不足扣分
```

子项口径：

- 资金改善幅度：今日净流入相对前一日改善越大，分数越高。
- 流出转流入：前一日净流出、今日净流入得高分；连续流出但流出大幅收窄得中等分。
- 抗跌或转强：全市场弱时板块跌幅更小、或由弱转强。
- 5/20 日趋势背景：5 日不连续破位、20 日相对强弱不在末位。
- 补涨空间：板块未极端过热，板块内存在放量启动但涨幅未充分释放的股票。
- 成交活跃改善：板块成交额和换手较前一日或近 5 日均值改善。
- 弱趋势扣分：20 日明显下行、板块内多数股票破位、资金和价格背离时扣分。

## 个股推荐模型

每个入榜板块输出两组股票，每组默认 3-5 只，按各自分数降序排序。

### 进攻龙头

`attack_leaders` 使用 `attack_score` 排序：

```text
attack_score =
  25% 板块内涨幅排名
+ 20% 成交额排名
+ 15% 量比和换手活跃
+ 15% 近 5/20 日相对板块强度
+ 15% 趋势突破或主升浪命中
+ 10% 流动性和市值稳定性
- 过热和连续大涨扣分
```

适用场景：

- 延续流入榜中，用于观察板块情绪是否继续。
- 轮动回流榜中，用于识别板块转强后的第一批攻击标的。

候选过滤：

- 排除停牌、退市、上市时间过短和流动性极低股票。
- 优先选择成交额不低于板块内中位数或全市场可交易阈值的股票。
- 对连续大涨、20 日位置极高且放量异常的股票降低分数但不强制剔除。

输出字段：

- `ts_code`
- `name`
- `industry`
- `close`
- `pct_chg`
- `amount`
- `turnover_rate`
- `volume_ratio`
- `attack_score`
- `reason`
- `pool_tag`

### 补涨候选

`catchup_candidates` 使用 `catchup_score` 排序：

```text
catchup_score =
  20% 板块资金改善暴露度
+ 20% 个股位置未过热
+ 15% 今日放量启动
+ 15% 均线修复或趋势改善
+ 15% 近 5 日跑输板块但未破位
+ 10% 成交额可交易性
+ 5% 自由复盘综合分加成
```

适用场景：

- 延续流入榜中，用于寻找板块扩散阶段的后排补涨。
- 轮动回流榜中，用于寻找资金回流时更可能被拉升的低位或修复票。

候选过滤：

- 不选择明显破位、成交极弱、财务质量过差且自由复盘风险旗标明显的股票。
- 排除短期涨幅已经显著高于板块且 20 日位置过高的股票。
- 保留今日初步放量、均线修复、仍有补涨空间的股票。

输出字段：

- `ts_code`
- `name`
- `industry`
- `close`
- `pct_chg`
- `amount`
- `turnover_rate`
- `volume_ratio`
- `catchup_score`
- `free_review_score`
- `reason`

## 前端设计

新增导航按钮：

```text
明日轮动
```

页面结构：

- 顶部摘要条：
  - 当前交易日
  - 使用的两日资金流日期
  - 延续榜最高分
  - 回流榜最高分
  - warnings 数量
- 两个并列或上下排列的榜单：
  - `延续流入榜`
  - `轮动回流榜`
- 每个榜单表格字段：
  - 排名
  - 板块
  - 主分数
  - 另一个参考分数
  - 信心
  - 信号
  - 今日净流入
  - 净流入变化
  - 上涨比例
  - 放量倍数
  - 推荐票摘要
- 点击或展开板块行后展示：
  - `进攻龙头`
  - `补涨候选`
  - 每只股票显示代码、名称、分数、涨幅、量比、成交额、推荐理由。

页面文案避免确定性表达，使用：

- `可能延续`
- `资金改善`
- `观察方向`
- `低置信度`

不使用：

- `必涨`
- `明天一定流入`
- `买入`
- `满仓`

## 降级和错误处理

- 最近完整交易日不足 2 天：返回空榜单，warnings 写明历史不足。
- 资金流只有 1 天：仍输出，但 `confidence` 最高为 `中`，不能标记高置信。
- 资金流完全缺失：返回空榜单，warnings 写明暂无足够资金流数据。
- 资金流日期和行情日期不一致：榜单可展示，但对应板块降低置信度。
- 行业样本少于 8 只：默认剔除，避免小样本噪音。
- 某板块无法计算个股推荐：板块可入榜，股票列表为空并给出 reason。
- 自由复盘分数不可用：补涨候选不使用该 5% 加成，其他分数重标化。

## 测试计划

后端单元测试：

- 构造两日资金流，验证连续净流入板块排在 `continuation_inflow` 前列。
- 构造前一日流出、今日流入板块，验证其排在 `rotation_rebound` 前列。
- 验证过热板块会被扣分，但不因单个条件被粗暴剔除。
- 验证资金流缺 1 天时 `confidence` 下降并生成 warnings。
- 验证资金流完全缺失时返回空榜单。
- 验证 `attack_leaders` 按 `attack_score` 降序。
- 验证 `catchup_candidates` 按 `catchup_score` 降序。
- 验证补涨候选在自由复盘分数缺失时仍可计算。
- 验证 API 参数边界：`limit`、`stocks_per_sector`、`trade_date` 格式。

前端测试：

- 工具函数格式化分数、金额、比例和 warnings。
- 页面包含 `明日轮动` 导航。
- 页面包含 `延续流入榜` 和 `轮动回流榜`。
- 空数据和低置信度状态有稳定展示。
- 展开行能显示进攻龙头和补涨候选。

集成验证：

- `GET /api/sector-rotation/tomorrow` 返回双榜结构。
- `GET /api/quant/sector-rotation/tomorrow` 经 Spring 正常代理。
- 前端可从 `8080` 或部署网关获取结果并渲染。

## 验收标准

- 页面存在独立 `明日轮动` 模块。
- 默认展示两个按分数排序的板块榜单。
- 每个板块有主分数、参考分数、信心等级、信号和理由。
- 每个入榜板块展示 `进攻龙头` 和 `补涨候选` 两组股票，且股票按分数排序。
- 资金流缺失、日期滞后、历史不足时页面不报错，并显示明确提示。
- 后端和前端相关测试通过。
