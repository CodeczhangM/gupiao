# 次日早盘跟进市场快照兜底设计

## 问题

14:30 后，次日早盘跟进会选择当天作为候选交易日。如果 Tushare 当天日线尚未发布，`sync_cached_market_data(force_current=True)` 后本地市场快照仍为空，`_load_follow_inputs` 会直接抛出 `LookupError`，最终接口返回 502。

实时信息模块已有全市场备用快照，但次日早盘跟进没有复用，因此分钟数据已经具备多源能力，候选池入口仍被 Tushare 单点阻断。

## 目标

- 保持现有次日早盘跟进筛选条件、评分、排序及计划文案不变。
- 当天本地市场快照未就绪时，使用东方财富全市场快照构建当天候选。
- 当天缓存、Tushare 强制同步和东方财富均不可用时，回退上一完整交易日，不再返回 502。
- 上一日兜底结果必须明确标记“备用缓存/非当日”，不能伪装成明日候选。
- 保留原始候选交易日和实际数据交易日，便于页面判断数据时效。

## 输入选择顺序

`_load_follow_inputs(now)` 按以下顺序选择市场数据：

1. 根据交易日历和当前时间计算计划候选日 `requested_candidate_trade_date`。
2. 读取该日期的本地市场快照。
3. 若候选日为当天且在 14:30 后，本地快照为空或需要盘中更新，则调用 Tushare 强制同步并重新读取。
4. 当天快照仍为空时，调用共享的 `load_eastmoney_market_snapshot`。
5. 东方财富快照必须：
   - 非空；
   - 证券代码及价格字段有效；
   - 包含筛选所需的涨跌幅、换手率、量比和成交额；
   - 至少存在一个满足次日早盘基础流动性范围的记录。
6. 当天所有来源均不可用时，选择交易日历中早于请求候选日的最近日期，并读取本地完整快照和历史数据。
7. 若上一完整交易日也没有快照，才抛出包含所有已尝试来源的 `LookupError`。

## 元数据

返回的 metadata 增加或明确以下字段：

- `requested_candidate_trade_date`：原计划使用的候选日。
- `candidate_trade_date`：实际用于构建候选池的交易日。
- `confirmation_trade_date`：`candidate_trade_date` 的下一交易日。
- `data_trade_date`：实际市场快照日期。
- `latest_trade_date`：交易日历中的最新日期。
- `data_current`：实际数据日是否等于请求候选日。
- `data_status`：`live` 或 `stale`。
- `data_status_label`：`实时数据` 或 `备用缓存`。
- `data_source`：`current_snapshot`、`eastmoney_snapshot_fallback` 或 `previous_snapshot`。
- `fallback_warnings`：Tushare、东方财富及回退原因的去重列表。

当回退上一交易日时，后续阶段、缓存键和分钟数据读取全部使用实际的 `candidate_trade_date`，避免用旧日股票池配当天尾盘数据。

## 页面和接口行为

- 接口保持 HTTP 200 并返回正常结构。
- 当 `data_status == "stale"` 时，页面在“次日早盘跟进”标题附近显示“备用缓存”和实际数据日期。
- 备注中加入“当前候选日快照未就绪，展示最近完整交易日计划”，避免误认为下一交易日仍是原请求日期。
- 只有三个来源都没有可用市场数据时才返回 502。

## 错误处理

- Tushare 同步异常被记录到 `fallback_warnings`，继续尝试东方财富。
- 东方财富请求异常、空数据或筛选字段不可用被记录后，继续尝试上一完整交易日。
- 东方财富成功时不读取上一日快照。
- 回退上一日成功时不沿用原请求日的 `confirmation_trade_date`，而是根据实际候选日重新计算。

## 测试

1. 当天本地快照缺失、强制同步仍为空时使用东方财富当天快照。
2. 东方财富返回空或字段不可用时回退上一完整交易日。
3. 回退结果的 `candidate_trade_date`、`confirmation_trade_date` 和状态字段一致。
4. 所有来源均不可用时，错误消息列出实际尝试的来源。
5. 已存在当天本地快照时不调用东方财富。
6. 运行现有早盘跟进、实时信息、API 和前端回归测试。

## 验收标准

- 用户给出的 `20260730 市场快照未就绪` 场景不再返回 502，只要东方财富当天快照或上一完整交易日快照任一可用。
- 当天东方财富快照可用时，候选日仍为 `20260730`。
- 使用上一日数据时，接口与页面均明确显示备用缓存及实际日期。
- 现有筛选阈值和候选排序不发生变化。
