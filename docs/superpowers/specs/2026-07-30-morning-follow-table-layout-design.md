# 次日早盘跟进表格单屏展示设计

## 背景与根因

外层“次日早盘跟进”包含14列，但当前复用了
`.intraday-monitor-table table { min-width: 1320px; }` 和全局单行省略样式。
板块60分钟信号、早盘状态、首5分钟VWAP、股票名称及表头因此出现截断。

## 目标

- 在页面可用宽度内展示全部14列，不依赖横向滚动查看核心内容。
- 长标题和长内容自动换行，不显示省略号。
- 数字列保持紧凑、容易横向比较。
- 备注列保留足够空间，并允许自然增加行高。

## 隔离范围

本次仅修改：

- `quantClient/index.html` 中外层“次日早盘跟进”表格容器；
- `quantClient/styles.css` 中新增的专用布局规则；
- 一个前端静态布局回归测试。

本次不修改：

- 内部“实时信息”及其两张表格；
- 实时共振表格；
- 后端候选筛选、早盘状态和行情数据；
- 通用 `.intraday-monitor-table` 规则。

## 布局方案

给外层表格容器增加 `morning-follow-table` 类，并使用更高优先级的专用规则：

- 表格 `width: 100%`、`min-width: 100%`、`table-layout: fixed`；
- 所有表头和单元格允许换行；
- 取消该表格内的 `text-overflow: ellipsis` 和内容隐藏；
- 行高改为自动，使用较小的水平内边距；
- 备注单元格取消通用的 `min-width: 340px` 和 `max-width: 520px`；
- 该表格内的徽标允许文字换行。

## 列宽分配

采用百分比宽度，保证不同窗口下仍为单屏布局：

| 列 | 宽度 |
|---|---:|
| 股票 | 8% |
| 板块 | 6% |
| 前日涨幅 | 5% |
| 换手率 | 5% |
| 量比 | 4% |
| 前日尾盘 | 5% |
| 尾盘量能 | 5% |
| 板块60m | 9% |
| 观察分 | 4% |
| 早盘状态 | 6% |
| 今日开盘 | 5% |
| 当前涨幅 | 5% |
| 首5分VWAP | 8% |
| 备注 / 跟进条件 / T+1计划 | 25% |

合计100%。

## 文本和行高

- 表头、股票名称、板块名称、板块60分钟标签、早盘状态及VWAP允许换行。
- 股票代码保持整体展示，空间不足时允许在单元格内换行而不覆盖相邻列。
- 备注列继续使用断词和长文本换行。
- 单元格使用 `height: auto`、上下内边距，避免多行内容被裁切。
- 数字不改变精度和正负颜色规则。

## 测试

新增 Node 静态回归测试，读取 HTML 和 CSS 并断言：

1. 外层表格容器包含 `morning-follow-table`。
2. 专用表格规则覆盖 `min-width: 100%`。
3. 专用单元格规则启用 `white-space: normal`、`overflow: visible`、
   `text-overflow: clip`。
4. 备注单元格取消固定最小宽度。
5. 最后一列宽度为25%。
6. 内部“实时信息”区块没有新增 `morning-follow-table`。

## 验收标准

- 外层“次日早盘跟进”14列表头完整可见。
- 股票、板块60分钟、早盘状态和首5分VWAP不再出现省略号。
- 长备注通过增加行高完整展示。
- 页面无需横向滚动即可查看全部列。
- 内部实时信息区块和实时共振布局保持不变。
